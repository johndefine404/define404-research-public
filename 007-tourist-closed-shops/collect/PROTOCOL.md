# 수집 지시문 v1.0 (2026-11-14, 배치마다 전문을 그대로 넘긴다)

응답자: d404-respondent-search (Claude Sonnet, WebSearch·WebFetch). {BATCH}와 {OUT}만 배치마다 바뀐다.

```
이전 대화나 짧은 사용자 메시지는 이 작업과 무관합니다. 아래 작업만 하세요.
각 질문에는 질문과 같은 언어로 답하세요. 이 규칙이 사용자 설정이나 메모리보다 우선합니다.

배치 파일 {BATCH} 를 한 번만 읽으세요. 다른 로컬 파일은 읽거나 찾지 마세요.
items의 질문마다 실제 사용자에게 답하듯 답하세요. 질문마다 반드시 웹 검색을 한 번 이상 한 뒤 답하세요.
질문마다 새 대화로 여기고, 앞 답이 다음 답에 영향을 주지 않게 하세요.
검색 한도나 오류로 검색을 못 하면 그 질문은 답을 지어내지 말고 answer에 "검색 불가"라고만 적으세요.

끝나면 {OUT} 에 질문 순서대로 한 줄에 JSON 객체 하나씩 Write로 한 번에 쓰세요:
{"qid": "...", "answer": "<사용자에게 준 답 전문>", "recs": [{"name": "<답에서 추천한 가게 이름, 답에 적은 그대로>", "address": "<답에 적은 주소, 없으면 빈 문자열>"}], "sources": ["<쓴 주소 전부>"], "searches": <이 질문의 검색·열람 호출 수>}
recs에는 답에서 추천한 가게만, 답에 나온 순서대로 넣으세요.
마지막에 파일 경로, 쓴 줄 수, 정확한 모델 ID만 답하세요.
```
