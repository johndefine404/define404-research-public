# 사전 등록: Local404

- 제목: AI는 폐업한 동네 가게를 아직 영업 중이라고 말하는가: 한국 일반음식점 800곳, 5개 언어, 4개 응답 시스템 측정
- 저자: 김하원 (Define404)
- 작성: 2026-10-21 (Asia/Ho_Chi_Minh). 본 수집 전. 시범 수집 80답(4곳)은 분석에서 뺀다.
- 버전 1.0

## 1. 연구 질문

AI 비서는 한국 동네 음식점의 영업 여부, 주소, 업종을 얼마나 정확히 말하는가. 폐업 여부, 질문 언어, 웹 검색 사용, 폐업 뒤 지난 기간, 지도 서비스 등록 여부에 따라 달라지는가.

## 2. 가설 (방향 포함)

- H1 (1차): 폐업한 가게를 "영업 중"이라고 답하는 비율은, 영업 중인 가게를 "폐업"이라고 답하는 비율보다 높다.
- H2: 한국어가 아닌 질문(EN·JA·ZH·VI)의 정답률은 한국어 질문보다 낮다.
- H3: 검색 조건의 오류율(틀림 비율)은 같은 모델의 기억 조건보다 낮다. (Haiku 검색 대 Haiku 기억으로 짝 비교)
- H4: 폐업 가게에서 "영업 중" 오답 비율은 폐업 뒤 지난 기간이 길수록 낮다.
- H5: 같은 가게·같은 시스템에서 5개 언어 답의 영업 상태 판정이 모두 같지 않은 가게가 존재하며, 그 비율은 0보다 크다(일관성 비율을 정확도와 따로 보고).

## 3. 모집단과 표본

- 원천: 지방행정 인허가 "식품_일반음식점" 전국 파일(file.localdata.go.kr, 2026-10-21 수신, 2,305,461행, SHA256 2b548c6e…ab24b4). 2일 전 기준 현행화 자료.
- 제외: 주소 없음, 상호 2자 미만, 같은 시군구에 같은 상호 2행 이상, 폐업인데 폐업일자 없음.
- 지역: 특별·광역시와 세종, 옛 광주광역시 5개 구 = 광역. 나머지 = 도.
- 층: 영업상태(영업/폐업) x 카카오 장소 등록(있음/없음) x 지역(광역/도), 층마다 100곳, 합계 800곳.
- 카카오 등록 있음 = "시도약칭 시군구 상호" 키워드 검색 결과 중, 상호가 같거나 한쪽이 다른 쪽을 포함하고 주소에 같은 시도·시군구가 있는 장소가 1곳 이상.
- 추출: 층 후보를 관리번호로 정렬하고 시드 20261021로 섞은 뒤 앞에서부터 판정해 채운다. 결과 sampling/sample_v2.csv (SHA256 4aaf1ecd…bc24871), 코드 sampling/draw_sample_v2.py.
- 표본 크기 근거: H1에서 10%p 차이, 유의수준 5%, 검정력 80%, 최악 비율 0.5일 때 집단당 약 392. 영업 400 대 폐업 400.

## 4. 질문

- 가게마다 1문항(영업 여부, 주소, 업종). 질문 틀 collect/question_templates.json v1.1. 상호와 시군구는 모든 언어에서 한국어 표기를 쓴다. 업종은 질문에 넣지 않는다.
- 언어: 한국어, 영어, 일본어, 중국어(간체), 베트남어.

- Claude 응답자는 하위 에이전트로 부른다. 한 호출 = 한 언어, 서로 다른 가게 최대 50문항, 문항 순서는 시드로 섞는다. 응답자는 연구 목적·정답을 모른다.
- 수집 기간을 log.md에 적는다. 실패·빈 답은 최대 2번 재시도하고 그대로 기록한다.

## 6. 판정

- 영업 상태: 답을 "영업 중이라 단정 / 폐업이라 단정 / 모름(확인 불가)" 3분류. 정답은 인허가 영업상태명.
- 주소: 답에 나온 주소가 정답 주소와 같은 읍면동 또는 도로명까지 맞으면 맞음, 다르면 틀림, 없으면 모름.
- 업종: 답의 업종이 업태구분명과 같은 묶음(한식, 중식, 일식, 양식·경양식, 분식, 치킨·호프, 카페, 기타)이면 맞음.
- 느슨한 판정(영업 상태만) / 엄격한 판정(영업 상태·주소·업종 중 말한 것이 전부 맞음) 두 방식.
- 자동 판정 규칙은 judge/rules.md로 본 수집 전에 고정한다. 무작위 200답을 사람 2명이 서로 모르게 판정해 일치율과 코헨 카파를 낸다.

## 7. 분석

- 1차(H1): 폐업 가게 중 "영업 중" 단정 비율과 영업 가게 중 "폐업" 단정 비율의 차이. 시스템별, 가게 단위 군집 표준오차로 95% 신뢰구간과 검정.
- H2: 언어별 정답률, 한국어 대비 같은 가게 짝 차이.
- H3: Haiku 검색 대 Haiku 기억, 같은 가게·같은 언어 짝 차이.
- H4: 폐업 가게 하위 표본에서 "영업 중" 단정 여부 ~ log(폐업 뒤 일수) 로지스틱, 가게 무작위 절편.
- H5: 시스템별 5개 언어 판정이 모두 같지 않은 가게 비율과 신뢰구간.
- 종합 모형: 정답 ~ 언어 + 영업상태 + 카카오 등록 + 지역 + 시스템 + (1 | 가게), 혼합효과 로지스틱.
- H1~H5는 Holm 보정. 표본 40 미만 칸은 해석하지 않는다. 그 밖의 분석은 모두 "탐색"으로 표시한다.

## 8. 제외 기준 (분석 단계)

- 응답 시스템 오류로 답이 비어 재시도 후에도 없는 문항은 결측으로 두고 비율을 보고한다.
- 판정 규칙을 본 수집 뒤에 바꾸면 원 규칙 결과를 함께 싣는다.

## 9. 한계로 미리 적는 것
