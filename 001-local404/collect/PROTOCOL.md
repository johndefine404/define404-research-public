# Local404 수집 규약 v1 (2026-10-21, 사전 등록 전 초안)

## 응답자 시스템 (2 모델 x 2 조건 = 4)

| 코드 | 모델 | 조건 | 도구 |
|---|---|---|---|
| S-search | Claude Sonnet (하위 에이전트) | AI 검색 | WebSearch, WebFetch만 |
| S-mem | Claude Sonnet (하위 에이전트) | AI 기억 | 도구 사용 금지 |
| H-search | Claude Haiku (하위 에이전트) | AI 검색 | WebSearch, WebFetch만 |
| H-mem | Claude Haiku (하위 에이전트) | AI 기억 | 도구 사용 금지 |

- 모델 정확 버전은 하위 에이전트 결과에서 확인해 기록한다.
- 비용: 연구자 개인 Claude 구독 안에서 돌렸다. 추가 과금 없음.

## 독립성

- 응답 에이전트는 질문 문장만 받는다. 정답 데이터, 표본 파일, 연구 목적을 알려 주지 않는다. 파일을 읽지 않게 지시하고, 결과의 도구 사용 기록으로 확인한다.
- 한 에이전트는 한 언어의 서로 다른 가게 20곳만 맡는다. 같은 가게의 다른 언어는 다른 에이전트가 맡는다(언어 간 일관성 측정 보호).
- 배치 안 문항 순서는 시드로 섞는다. 같은 배치 안 맥락 효과는 한계 절에 적는다.

## 기록

- 문항마다: item_id, 언어, 시스템 코드, 배치 번호, 질문 원문, 답 원문, 검색 출처 주소, 수집 시각, 도구 호출 수.
- raw/ 에 배치마다 JSONL 한 파일. 고치지 않는다. 실패·빈 답은 그대로 남기고 최대 2번 재시도.

## 규모

- 800곳 x 5개 언어 x 4 시스템 = 16,000 답, 배치 20문항이면 800 에이전트 호출.
- 시범 20문항 x 4 시스템으로 형식과 도구 제한을 먼저 확인한다(분석 제외).
