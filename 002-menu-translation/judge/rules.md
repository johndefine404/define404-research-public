# 판정 규칙 v1.0 (본 수집 전 고정, 2026-10-28)

사전 등록 prereg.md 6절의 상세. 정답 원천은 한식진흥원 한식포털 "한식메뉴 외국어 표기법"(길라잡이 800선, 778건, sampling/raw/hansik_menu_800_20261028.csv). 규칙 자동 판정(judge/auto_judge.py)만 쓰고, 규칙으로 못 뽑은 칸만 허브가 직접 판정해 건수를 밝힌다. LLM 판정자는 쓰지 않는다.

## 1. 단위

- 한 문항 = 메뉴 1개 x 언어 1개(en, ja). 메뉴가 군집이다.
- 판정 대상은 답에서 뽑은 "메뉴명 후보" 1개다. 설명 문장은 판정하지 않는다.

## 2. 메뉴명 후보 뽑기

1. 답 본문에서 첫 번째 NAME: 표시 (대소문자 무시, 전각 콜론 허용) 뒤의 같은 줄 글자를 후보로 삼는다. 앞뒤 따옴표·괄호 설명·마침표를 뗀다.
2. NAME: 표시 줄이 없으면 첫 줄이 20자(영어는 8단어) 이하이고 문장 부호로 끝나지 않을 때 그 줄을 후보로 삼는다.
3. 둘 다 아니면 "추출 실패"로 표시하고 허브가 직접 후보를 뽑는다. 직접 뽑은 건수와 qid를 judge/manual.csv에 남긴다.
4. 후보가 "A / B", "A or B", "A（B）"처럼 둘 이상이면 첫 번째를 후보로 삼고 "복수 제시" 표시를 남긴다. 괄호 안이 로마자 표기만이면 떼고 괄호 밖만 본다.
5. 답이 비어 있거나 "모른다, 확인할 수 없다"만 있으면 "미제시"다.

## 3. 정규화

- 영어: 소문자, NFKC, 괄호 안 제거, 문장 부호·하이픈·슬래시를 공백으로, 관사(a, an, the)와 "and"·"&"·"with"를 공백으로, 연속 공백 하나로. 표기 변형 "kimchi/gimchi", "tteok/ddeok/dduk", "jjigae/chigae", "guk/gook", "bap/bab", "tang/tahng" 은 앞 형태로 통일한다(사전 judge/auto_judge.py VARIANTS).
- 일본어: NFKC, 공백·중점(・)·장음 기호(ー)·괄호 안 제거. 가타카나 소문자 "ッ" 유무는 무시한다.

## 4. 판정 (언어마다 같은 틀)

- 엄격 일치: 정규화한 후보가 정규화한 표준(en 열 또는 ja 열)과 같다.
- 느슨한 일치: 엄격 일치가 아니면서 다음 중 하나. (a) 영어: 후보와 표준의 낱말 집합 자카드 계수 0.5 이상, 또는 후보가 표준의 로마자 표기(latin 열, 정규화)를 통째로 담고 있다. (b) 일본어: 후보와 표준의 글자 2-gram 다이스 계수 0.5 이상, 또는 후보가 표준을 통째로 담고 있다.
- 불일치: 위 둘 다 아닌 경우.
- 미제시: 2절 5번.
- 세 비율(엄격·느슨·불일치)은 미제시를 분모에 넣고 따로 보고한다. "느슨 이상" = 엄격 + 느슨.

## 5. 출처 표시 (H2용)

- 답 기록의 sources 목록에 hansik.or.kr 이 하나라도 있으면 "표준 출처 참조"다. 그 밖은 "미참조".

## 6. 탐색 표시 (사전 등록 분석 아님)

- 불일치 답 가운데 표준의 핵심 재료 낱말(영어 표준의 명사 가운데 사전 judge/auto_judge.py INGREDIENTS에 있는 것)이 후보에 없고 다른 재료 낱말이 있는 경우를 "재료 불일치"로 표시한다. 수치는 탐색으로만 싣는다.
